# TM261 Session Survey – Setup & Hosting Instructions

**Purpose:** Collect structured feedback from session participants on the session experience, content quality, agent performance, and reliability observations. The survey runs independently of any organiser-provided feedback channels and gives the presenter team direct, unfiltered input.

---

## What Has Been Built

All survey components are ready in the session repo (`SAP-samples/teched2026-TM261`):

| File | Purpose |
|---|---|
| `docs/survey.html` | The participant-facing form (hosted via GitHub Pages) |
| `_dev/decrypt_responses.py` | Post-session decryption script; run locally to produce a CSV |
| `_responses/.gitkeep` | Placeholder keeping the responses folder visible in the repo |

**Technical setup:**
- Form collects workstation number + survey answers
- Responses are encrypted (AES-256-GCM) in the browser before submission
- Encrypted files are written to `D050168/team-brain-pilot/tm261-survey/ws###_survey.json` — one file per workstation, via the GitHub API
- A participant who submits twice is rejected at the API level (first write wins)
- Encryption passphrase: `TM261-Berlin-2026` (required for decryption — store securely)
- GitHub PAT (`TM261-survey`, expires 2026-11-06): already embedded in `docs/survey.html`; scoped to `D050168/team-brain-pilot` Contents only; revoke after the session at github.com → Settings → Developer settings → Personal access tokens

## Hosting Situation

The session repo (`SAP-samples/teched2026-TM261`) is **public** but GitHub Pages is **not enabled** — it requires org admin access. Without Pages, the survey form has no live URL participants can reach.

**What works without Pages:**
- Exercise READMEs: readable in the GitHub UI at github.com/SAP-samples/teched2026-TM261
- PDF and HTML script: downloadable from `_FINAL SCRIPTS/`
- Survey form: accessible only to presenters locally (file://) — not usable by participants

## Pending: Hosting Decision

Two options to make the survey live for participants:

### Option A — Personal account hosting (no admin required, self-service)

1. Create a **public** repo under `D050168` (e.g. `tm261-survey-host`)
2. Copy `docs/survey.html` into the root of that repo
3. Go to repo Settings → Pages → Source: Deploy from branch → `main` / `/ (root)`
4. GitHub assigns a URL: `https://d050168.github.io/tm261-survey-host/survey.html`
5. Put that URL on the closing slide as a QR code

Responses still go to `D050168/team-brain-pilot/tm261-survey/` (private) — unaffected by where the form is hosted.

### Option B — Enable GitHub Pages on SAP-samples/teched2026-TM261 (org admin required)

Ask whoever manages the SAP-samples GitHub org to enable Pages for this repo (deploy from `docs/` branch `main`). This also makes the compiled session guide available as a live URL for participants — a separate benefit.

Survey URL would be: `https://sap-samples.github.io/teched2026-TM261/survey.html`

## Post-Session: Collecting Responses

1. Open `D050168/team-brain-pilot` on github.com → browse to `tm261-survey/` — encrypted response files visible there
2. Clone or pull the `team-brain-pilot` repo locally
3. From the repo root, run:
   ```
   py -I [path-to]/teched2026-TM261/_dev/decrypt_responses.py
   ```
   Output: `tm261-survey/_decrypted.csv`
4. Revoke the PAT: github.com → profile → Settings → Developer settings → Personal access tokens → TM261-survey → Delete
