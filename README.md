# TM261 — Agent-Led Test Management: Hands-on Lab with Joule in SAP Cloud ALM

## Description

This repository contains the hands-on exercise material for **SAP TechEd 2026 Session TM261**.

**Session:** Agent-Led Test Management: Hands-on Lab with Joule in SAP Cloud ALM  
**Date:** Thursday, 29 October 2026  
**Location:** SAP TechEd 2026, Berlin  
**Presenters:** Christina Pickhardt · Niclas Weidner · Tobias Keller

In this session you'll experience how AI agents in SAP Cloud ALM Test Management accelerate every stage of test preparation — from generating requirements out of an interview transcript to writing executable test cases and suggesting test data — for the **Sales Order Processing with Customer Down Payment** (Scope Item BKJ) scenario.

## Overview

The hands-on follows the story of a **Test Business Process Expert** preparing test coverage for a newly activated S/4HANA process in a single session — work that would otherwise take 3–5 days. You'll work with four AI agents (scoping, planning, test case generation, test data) and Joule throughout.

**Session flow:**

| # | Exercise | What you'll do |
|---|---|---|
| 0 | Getting Started | Log in, meet Joule, set up project context |
| 1 | Generate Requirements | Turn an interview transcript into structured requirements with AI |
| 2 | Scope with AI | Unleash the scoping agent; compare with manual scoping |
| 3 | Plan with AI | Unleash the planning agent; review and refine the test plan |
| 4 | Generate Test Cases | Unleash the TC generation agent; review quality and understand parameters |
| 5 | Generate Test Data | Unleash the data agent; explore dependencies and meaningful data variants |
| 6 | Recap & Outlook | Reflect on the time saved; preview what's coming next |
